# Required Images for Zandile.M Stories Website

Upload the following images to this folder: `public/assets/images/`

## 1. **zandiii.jpg**
- Your author profile photo
- Recommended: Professional portrait
- Size: Any size (will be displayed at max 600px height)
- Format: JPG or PNG

## 2. **bg-shade_5.png**
- Background pattern for sticky header (when scrolling)
- Used in header background
- Format: PNG (transparent or with pattern)

## 3. **brush-stroke-red.png**
- Red brush stroke for navigation hover effect
- Should be a horizontal brush stroke
- Format: PNG with transparent background
- Color: Red (#EF4444 or similar)

## 4. **divider.jpg**
- Decorative divider line below hero section
- Should be a horizontal pattern/line
- Will repeat horizontally across the page
- Height: Works best at 5-10px tall
- Format: JPG or PNG
