### 2. brush-stroke-red.png
**Red brush stroke image for navigation hover effect**

Download a red brush stroke PNG with transparent background from:
- https://www.freeiconspng.com/img/25126
- https://www.pngmart.com/image/tag/red-brush-stroke
- https://www.vecteezy.com/free-png/red-brush-stroke

**Requirements:**
- Transparent background (PNG format)
- Red color (#EF4444 or similar)
- Horizontal brush stroke orientation
- Recommended size: 200-400px width

**File name:** `brush-stroke-red.png`

After downloading, place the image in this folder:
`public/assets/images/brush-stroke-red.png`
